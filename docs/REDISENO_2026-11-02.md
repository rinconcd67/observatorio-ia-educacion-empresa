# Rediseño del Observatorio — 2 de noviembre de 2026

## Cambios incluidos

- Fondo blanco, colores vivos y sello amarillo, azul y rojo con globo central.
- Dos ilustraciones pedagógicas optimizadas en WebP; 231400 bytes combinados.
- Búsqueda unificada en países, publicaciones, formación y 30 fuentes oficiales; filtros y paginación.
- Navegación local coherente en español e inglés; biblioteca y Skills con identidad compartida.
- Portada con contenido HTML inicial y enlaces rastreables, además de su versión interactiva. Sitemap con 110 páginas canónicas y alternancias de idioma recíprocas.
- Boletín con edición de muestra. En producción no se solicita correo ni se simula una suscripción; el formulario de ensayo sólo aparece en localhost.
- Adaptador opcional para contador gratuito GoatCounter. Desactivado hasta conectar y comprobar la cuenta del propietario; sin cifras inventadas. No se creó infraestructura Supabase ni se aprobó un cargo.

## Validación

La revisión visual cubrió escritorio (1280 × 720) y móvil (390 × 844), con pruebas adicionales previas a 320 y 768 px. No se observó desbordamiento horizontal. Se comprobaron sello, búsquedas, filtros, navegación ES/EN, biblioteca, Skills, menú móvil y estados vacíos.

La integridad analítica mantiene 5280 observaciones, 218 países y 40 países con medición directa. Se conservan las fechas efectivas de datos, noticias y biblioteca. Las pruebas de contenido, navegación, SEO y analítica se ejecutan mediante `npm run check`; el control de publicación compara el candidato con la línea base. Una prueba de archivos originales se omite en copias que no contienen las descargas no versionadas.

La revisión no equivale a una auditoría completa WCAG ni garantiza indexación. El despliegue se valida mediante los checks nativos del PR y el workflow de GitHub Pages; Search Console se observa por separado después de publicar.
