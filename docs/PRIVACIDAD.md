# Política de privacidad

El observatorio no solicita cuentas, contraseñas, pagos ni datos personales de sus visitantes. La versión inicial no utiliza cookies propias ni herramientas de analítica de terceros.

GitHub Pages y la infraestructura de red asociada pueden procesar registros técnicos conforme a sus propias políticas. Los enlaces externos conducen a servicios con políticas independientes.

Las consultas de correspondencia se realizan voluntariamente mediante correo electrónico y no se almacenan en el dashboard.
