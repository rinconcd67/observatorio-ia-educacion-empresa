# Política de datos

## Principios

- Se utilizan fuentes públicas y documentadas.
- Cada observación conserva fuente, periodo, unidad y procedencia.
- Los valores ausentes no se imputan ni se convierten en cero.
- Los índices con metodologías distintas se mantienen separados.
- Las actualizaciones requieren controles de cobertura, rango, duplicados y variación.
- Las comparaciones derivadas requieren coincidencia de país y año; no se restan periodos diferentes.
- Las fuentes dinámicas no fijan manualmente un año final y las ediciones históricas se mantienen explícitamente fijadas.
- Las huellas SHA-256 representan los bytes exactos almacenados o publicados y declaran su alcance.

## Publicación

El sitio publica datos procesados para consulta y descarga. Los archivos crudos se mantienen fuera de Git y están sujetos a las condiciones de sus proveedores. Una actualización automática produce una versión candidata; su publicación requiere validación y aprobación humana.

## Correcciones

Las correcciones se documentan en el historial de cambios. Una modificación metodológica genera una nueva versión del observatorio.
